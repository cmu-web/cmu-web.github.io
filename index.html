CMU Web Projects

Each one builds on Carnegie Mellon's web template and follows its look. For brand questions, see brand.cmu.edu.

Carnegie Mellon Web Kilt

Components for websites and web apps on CMU's template.

FencePost

Link previews for Carnegie Mellon websites: the image and the Open Graph tags.

Jekyll & Plaid

A GitHub Pages theme that turns plain Markdown into pages in CMU style.

PlaceMellon

Placeholder photos of Carnegie Mellon at any size, for mockups and prototypes.

QRnegie

QR codes with Carnegie Mellon character, from Scotty portraits to campus landmarks.
