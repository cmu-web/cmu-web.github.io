# Projects

Each one builds on Carnegie Mellon's web template and follows its look; for
brand questions, see [brand.cmu.edu](https://www.cmu.edu/brand/).

| Project | What It Does |
| --- | --- |
| [Carnegie Mellon Web Kit](https://cmu-web.github.io/cmu-web-kit/) | CSS and JavaScript components for CMS sites and web apps, extending the CMU web template. |
| [Carnegie Mellon Web Markdown](https://cmu-web.github.io/cmu-web-markdown/) | A GitHub Pages theme that turns plain Markdown into pages in CMU style. This page uses it. |
| [PlaceMellon](https://cmu-web.github.io/cmu-web-placemellon/) | Placeholder photos of Carnegie Mellon for mockups and examples. |

Maintained by the Office of the Vice Provost for Teaching and Learning
Innovation at Carnegie Mellon University. Questions and suggestions are
welcome in each project's [GitHub issues](https://github.com/cmu-web).
